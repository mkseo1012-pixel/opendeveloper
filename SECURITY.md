# Security policy

OpenDeveloper v0.1 is an early local-only tool. Do not expose its server to other machines. Use only trusted local accounts. Keep Python and the OS current. Model-generated code requires human review before execution or publishing.

Do not place credentials in issues, prompts, screenshots, generated artifacts or commits. For vulnerabilities, use the repository's private vulnerability reporting when enabled; otherwise request a private contact without posting exploit details or secrets publicly.
